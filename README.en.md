<h2 id="about">📖 About</h2>
Academic project for the Web Development course, taught by professor Carlos Rafael Magalhães Fernandes at Impacta College, during the second semester of the Systems Analysis and Development program, taken in the 1st semester of 2025.
<br><br>The project consists of a Web Application that consumes an API provided by the professor to perform Address Management.<br>
To serve as the basis for developing the Web Application, a fictional company called DivsMootors was defined, operating as an intermediary for vehicle sales with a focus on high-end cars.<br><br>
After the end of the academic semester, access to the API will be blocked, so the features that require API authorization will no longer be available.
<br><br>
Professor's API repository: <a href="https://github.com/carlosrmfernandes/address-management">address-management</a>

<h2 id="how-it-works">⚙️ Features</h2>
🔹 User Registration: The user must register in the system, providing information such as name, email, CPF, and other required data.
<br>🔹 Account Activation: After registration, the system sends an activation email. The user must click the link sent to activate the account.
<br>🔹 Login: After activating the account, the user can log in to the system with email and password, receiving a JWT token for authentication.
<br>🔹 Address Management: The user can create, list, update and delete addresses.
<br>🔹 Logout: The user can log out of the system.
